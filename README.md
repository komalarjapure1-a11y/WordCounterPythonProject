# Word Counter & Text Analyzer

## Project Description
Word Counter & Text Analyzer is a Python-based application that analyzes text and provides useful statistics.

## Features
- Count total words
- Count total characters
- Count sentences
- Count paragraphs
- Count unique words
- Calculate word frequency
- Display top frequently used words
- Show frequency graph
- Open text files
- Save analysis report
- Clear input and output

## Modules

### Module 1 – Input & File Handling
Handles text input and opening text files.

### Module 2 – Text Processing & Statistics
Processes the text and calculates word, character, sentence, paragraph and unique word statistics.

### Module 3 – Frequency Analysis & Visualization
Calculates word frequency and displays the Top 10 most frequently used words in a graph.

### Module 4 – Output & Report Management
Handles saving the report, clearing the text and button hover effects.

## Technologies Used
- Python
- Tkinter
- Regular Expressions
- Collections Counter
- Matplotlib
